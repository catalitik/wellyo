# Wellyo

Base del MVP de Wellyo: aplicación web responsive para registrar nutrición, movimiento, composición corporal y hábitos.

## Desarrollo local

1. Instala Node.js 20+ y pnpm.
2. Ejecuta `pnpm install`.
3. Copia `.env.example` como `.env.local` y completa las variables cuando se cree el proyecto de Supabase.
4. Ejecuta `pnpm dev` y abre `http://localhost:3000`.

La fase 1 incluye la estructura App Router, configuración TypeScript/Tailwind, página inicial responsive y la dirección visual pastel verdosa. La integración de autenticación, base de datos y el proveedor nutricional se añadirá en las siguientes fases, sin credenciales en el repositorio.
